# TigerBeetle

**Status:** Planning

This experiment explores how TigerBeetle behaves as a financial transactions database under load and during failure.

## Questions

- What does a minimal reproducible TigerBeetle deployment require?
- How does it behave under a repeatable transaction workload?
- What happens when a node or its network fails?
- What operational information is available during failure and recovery?
